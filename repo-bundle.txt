# Template para Generar Secciones de Datos con IA (Gemini)

Este documento contiene la plantilla que puedes copiar y enviar a Gemini (o cualquier LLM) junto con el tema o pregunta deseada para generar objetos JSON individuales e importarlos en `data/items/`.

---

## 📋 Prompt para Gemini

Copia y pega el siguiente texto en Gemini, sustituyendo la línea del tema por la pregunta o tema que quieras investigar:

```text
Actúa como un analista de datos especializado en datos públicos u oficiales de España (INE, Banco de España, Ministerios, Eurostat, CIS). 

Tu objetivo es generar una tarjeta de datos completa en formato JSON para nuestra plataforma de transparencia pública ("Factores").

REGLAS DE ORO DE LA PLATAFORMA:
1. NEUTRALIDAD RADICAL: Cero adjetivos valorativos, juicios de valor ni opiniones políticas. El texto debe ser 100% neutro, técnico, desapasionado y objetivo.
2. SERIE HISTÓRICA AMPLIA: Proporciona la serie temporal anual con el mayor recorrido posible (mínimo 10-15 años, idealmente desde 2010 o antes hasta el último dato publicado de 2024/2025). Evita recortes interesados de años.
3. DATOS PRECISOS Y FUENTE REAL: Utiliza datos reales de fuentes oficiales comprobables (INE, Banco de España, Ministerios, Eurostat, etc.).

TEMA O PREGUNTA SOLICITADA:
"[Escribe aquí la pregunta o tema. Ejemplo: ¿Cómo ha evolucionado la deuda pública sobre el PIB en España?]"

CATEGORÍAS PERMITIDAS (Elige exactamente una):
- "Vivienda"
- "Economía y Empleo"
- "Sanidad"
- "Pensiones y Demografía"

TIPO DE GRÁFICO PERMITIDO:
- "line" (para series temporales continuas)
- "bar" (para datos comparativos o de frecuencia)

FORMATO DE SALIDA:
Responde ÚNICAMENTE con un bloque de código JSON válido con la siguiente estructura exacta:

{
  "id": "slug-en-kebab-case-sin-acentos",
  "category": "Economía y Empleo",
  "question": "¿Pregunta clara, neutra y directa?",
  "chartType": "line",
  "unit": "% del PIB",
  "dataPoints": [
    { "year": "2010", "value": 60.1 },
    { "year": "2011", "value": 69.5 },
    { "year": "2012", "value": 86.3 }
  ],
  "contextNotes": [
    "Nota metodológica técnica 1 (qué mide exactamente el indicador).",
    "Nota metodológica técnica 2 (aclaraciones de ámbito o cambios de metodología si los hay).",
    "Nota metodológica técnica 3 (aclaración sobre qué incluye o excluye)."
  ],
  "source": {
    "institution": "Nombre completo del organismo oficial emisor",
    "lastUpdated": "AAAA-MM-DD",
    "url": "URL directa a la tabla, boletín o portal de datos oficial"
  }
}
```

---

## 🔍 Pasos para añadir la nueva tarjeta

1. **Crear archivo individual:** Guarda la respuesta JSON devuelta en un nuevo archivo dentro de `data/items/<id>.json` (por ejemplo, `data/items/deuda-publica-pib.json`).
2. **Registrar en `data/items/index.ts`:** Importa y añade la nueva variable al array `items` en `data/items/index.ts`.
3. **Checklist de verificación:**
   - Comprobar que el `id` es único.
   - La categoría coincide con una de las 4 permitidas.
   - Contrastar 2-3 puntos de la serie temporal con la fuente oficial.
   - Verificar que la URL oficial responde correctamente.
   - Comprobar que `contextNotes` sea 100% neutro sin sesgo ideológico.

"use client";

import { useEffect, useState } from "react";
import Link from "next/link";
import { GlobalMetadata, CountyDetail } from "@/types";
import { fetchMetadata, fetchCountyDetail, DATA_BASE_URL } from "@/lib/data-utils";
import InteractiveChart from "@/components/detail/InteractiveChart";
import SourceCard from "@/components/detail/SourceCard";
import { ArrowLeft, MapPin, Calendar, Loader2, AlertCircle, Filter } from "lucide-react";

interface CountyClientViewProps {
  countyId: string;
}

export default function CountyClientView({ countyId }: CountyClientViewProps) {
  const [metadata, setMetadata] = useState<GlobalMetadata | null>(null);
  const [county, setCounty] = useState<CountyDetail | null>(null);
  const [selectedMetric, setSelectedMetric] = useState<string>("");
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    async function loadCountyData() {
      try {
        setLoading(true);
        setError(null);
        const [metaData, countyData] = await Promise.all([
          fetchMetadata(),
          fetchCountyDetail(countyId),
        ]);

        if (!countyData) {
          setError(`County record '${countyId}' not found.`);
          return;
        }

        setMetadata(metaData);
        setCounty(countyData);

        const availableMetrics = Object.keys(countyData.metrics || {});
        if (availableMetrics.length > 0) {
          setSelectedMetric(availableMetrics[0]);
        }
      } catch (err) {
        console.error("Failed to lazy-load county detail:", err);
        setError(`Failed to fetch county data from ${DATA_BASE_URL}/counties/${countyId}.json`);
      } finally {
        setLoading(false);
      }
    }

    loadCountyData();
  }, [countyId]);

  if (loading) {
    return (
      <div className="bg-white rounded-2xl border border-slate-200 p-12 text-center space-y-3">
        <Loader2 className="w-6 h-6 animate-spin text-blue-600 mx-auto" />
        <p className="text-sm font-semibold text-slate-700">
          Lazy-loading county detail JSON via HTTP...
        </p>
      </div>
    );
  }

  if (error || !county) {
    return (
      <div className="space-y-4">
        <div>
          <Link
            href="/"
            className="inline-flex items-center gap-1.5 text-xs font-semibold text-slate-600 hover:text-slate-900 bg-white hover:bg-slate-100 border border-slate-200 px-3.5 py-2 rounded-full transition-colors shadow-xs"
          >
            <ArrowLeft className="w-3.5 h-3.5" />
            <span>Back to Explorer</span>
          </Link>
        </div>

        <div className="bg-white rounded-2xl border border-slate-200 p-8 text-center space-y-3">
          <AlertCircle className="w-6 h-6 text-red-600 mx-auto" />
          <h2 className="text-base font-bold text-slate-900">{error || "County Not Found"}</h2>
          <p className="text-xs text-slate-500">
            Requested County ID: {countyId}
          </p>
        </div>
      </div>
    );
  }

  const metricKeys = Object.keys(county.metrics || {});
  const currentMetricData = selectedMetric && county.metrics ? county.metrics[selectedMetric] : undefined;
  const currentMetricMeta = metadata?.metrics ? metadata.metrics[selectedMetric] : undefined;

  const unit = currentMetricData?.unit || currentMetricMeta?.unit || "";
  const title = currentMetricMeta?.title || selectedMetric;

  return (
    <article className="space-y-6 animate-in fade-in duration-200">
      {/* Back Button */}
      <div>
        <Link
          href="/"
          className="inline-flex items-center gap-1.5 text-xs font-semibold text-slate-600 hover:text-slate-900 bg-white hover:bg-slate-100 border border-slate-200 px-3.5 py-2 rounded-full transition-colors shadow-xs"
        >
          <ArrowLeft className="w-3.5 h-3.5" />
          <span>Back to Explorer</span>
        </Link>
      </div>

      {/* Header */}
      <header className="bg-white rounded-2xl border border-slate-200 p-5 sm:p-6 shadow-sm space-y-3">
        <div className="flex flex-col sm:flex-row sm:items-center justify-between gap-3">
          <div>
            <span className="inline-flex items-center gap-1 px-3 py-1 bg-blue-50 text-blue-700 border border-blue-100 rounded-lg text-xs font-semibold">
              <MapPin className="w-3.5 h-3.5 text-blue-600" />
              {county.state ? `${county.name}, ${county.state}` : county.name}
            </span>
            <h1 className="text-xl sm:text-2xl font-bold text-slate-900 mt-2 tracking-tight">
              {county.name} Dashboard
            </h1>
          </div>
          <div className="inline-flex items-center gap-1.5 text-xs font-medium text-slate-600 bg-slate-100 border border-slate-200 px-3 py-1.5 rounded-full self-start sm:self-auto">
            <Calendar className="w-3.5 h-3.5 text-slate-500" />
            <span>Updated: {county.last_updated || metadata?.last_updated}</span>
          </div>
        </div>
      </header>

      {/* Metric Selector Tabs */}
      {metricKeys.length > 1 && (
        <section className="space-y-2">
          <div className="flex items-center gap-1.5 text-xs font-semibold text-slate-500 uppercase tracking-wider">
            <Filter className="w-3.5 h-3.5" />
            <span>Select Metric Series</span>
          </div>
          <div className="flex flex-wrap gap-2">
            {metricKeys.map((key) => {
              const meta = metadata?.metrics ? metadata.metrics[key] : undefined;
              const isSelected = selectedMetric === key;
              return (
                <button
                  key={key}
                  onClick={() => setSelectedMetric(key)}
                  className={`px-4 py-2 rounded-xl text-xs font-semibold transition-all duration-150 ${
                    isSelected
                      ? "bg-slate-900 text-white shadow-sm ring-1 ring-slate-900"
                      : "bg-white text-slate-700 hover:bg-slate-100 border border-slate-200"
                  }`}
                >
                  {meta?.title || key}
                </button>
              );
            })}
          </div>
        </section>
      )}

      {/* Interactive Time-Series Chart */}
      {currentMetricData && (
        <section>
          <InteractiveChart
            series={currentMetricData.series}
            chartType="line"
            unit={unit}
            title={title}
          />
        </section>
      )}

      {/* Source Attribution & Traceability Card */}
      <section>
        <SourceCard
          sources={county.sources}
          lastUpdated={county.last_updated || metadata?.last_updated}
        />
      </section>
    </article>
  );
}

"use client";

import { useEffect, useState } from "react";
import Link from "next/link";
import { DatoItem } from "@/types";
import { fetchItemDetail, DATA_BASE_URL } from "@/lib/data-utils";
import InteractiveChart from "@/components/detail/InteractiveChart";
import SourceCard from "@/components/detail/SourceCard";
import { ArrowLeft, Tag, Loader2, AlertCircle } from "lucide-react";
import { t, translateCategory } from "@/lib/i18n";

interface DatoClientViewProps {
  slug: string;
  lang?: "es" | "en";
}

export default function DatoClientView({ slug, lang = "es" }: DatoClientViewProps) {
  const [dato, setDato] = useState<DatoItem | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    if (typeof document !== "undefined") {
      document.documentElement.lang = lang;
    }
  }, [lang]);

  useEffect(() => {
    async function loadItem() {
      if (slug === "_none") {
        setLoading(false);
        return;
      }
      try {
        setLoading(true);
        setError(null);
        const item = await fetchItemDetail(slug, lang);
        if (!item) {
          setError(lang === "en" ? `Indicator '${slug}' not found.` : `No se encontró el dato '${slug}'.`);
        } else {
          setDato(item);
        }
      } catch (err) {
        console.error("Error loading item detail:", err);
        setError(`Error fetching data from ${DATA_BASE_URL}/items/${slug}.json`);
      } finally {
        setLoading(false);
      }
    }
    loadItem();
  }, [slug, lang]);

  const backUrl = lang === "en" ? "/en" : "/";

  return (
    <div className="w-full space-y-6">
      {loading ? (
        <div className="bg-slate-900 rounded-2xl border border-slate-800 p-12 text-center space-y-3">
          <Loader2 className="w-6 h-6 animate-spin text-blue-400 mx-auto" />
          <p className="text-sm font-semibold text-slate-300">{t("loadingData", lang)}</p>
        </div>
      ) : error || !dato || slug === "_none" ? (
        <div className="space-y-4">
          <div>
            <Link
              href={backUrl}
              className="inline-flex items-center gap-1.5 text-xs font-semibold text-slate-300 hover:text-white bg-slate-900 hover:bg-slate-800 border border-slate-800 px-3.5 py-2 rounded-full transition-colors shadow-xs"
            >
              <ArrowLeft className="w-3.5 h-3.5" />
              <span>{t("backToExplorer", lang)}</span>
            </Link>
          </div>

          <div className="bg-slate-900 rounded-2xl border border-slate-800 p-8 text-center space-y-3">
            <AlertCircle className="w-6 h-6 text-red-500 mx-auto" />
            <h2 className="text-base font-bold text-white">
              {error || t("noDataYet", lang)}
            </h2>
            <p className="text-xs text-slate-400">
              {lang === "en" ? "You can add a new JSON data file in" : "Puedes añadir un nuevo dato JSON en"}{" "}
              <code className="bg-slate-800 px-1 py-0.5 rounded text-slate-300">data/items/{slug}.json</code>
            </p>
          </div>
        </div>
      ) : (
        <article className="space-y-6 animate-in fade-in duration-200">
          {/* Botón Volver */}
          <div>
            <Link
              href={backUrl}
              className="inline-flex items-center gap-1.5 text-xs font-semibold text-slate-300 hover:text-white bg-slate-900 hover:bg-slate-800 border border-slate-800 px-3.5 py-2 rounded-full transition-colors shadow-xs"
            >
              <ArrowLeft className="w-3.5 h-3.5" />
              <span>{t("backToExplorer", lang)}</span>
            </Link>
          </div>

          {/* Categoría Badge */}
          <div>
            <span className="inline-flex items-center gap-1.5 px-3 py-1 bg-blue-950 text-blue-300 border border-blue-800/80 rounded-lg text-xs font-semibold">
              <Tag className="w-3 h-3 text-blue-400" />
              {translateCategory(dato.category, lang)}
            </span>
          </div>

          {/* 1. La Pregunta (H1) */}
          <header className="space-y-2">
            <h1 className="text-xl sm:text-2xl font-bold text-white leading-snug tracking-tight">
              {dato.question}
            </h1>
          </header>

          {/* 2. El Gráfico Interactivo */}
          <section>
            <InteractiveChart
              series={dato.dataPoints.map((dp) => {
                let val = 0;
                const rawVal = dp.value as any;
                if (typeof rawVal === "number") {
                  val = rawVal;
                } else if (Array.isArray(rawVal)) {
                  const totalObj = rawVal.find((item: any) => item && typeof item === "object" && "total" in item) || rawVal[0];
                  val = totalObj ? (Object.values(totalObj)[0] as number) : 0;
                }
                return {
                  year: dp.year || dp.date || "",
                  date: dp.date || dp.year || "",
                  value: val,
                };
              })}
              rawPoints={dato.dataPoints}
              continentsPoints={(dato as any).continentsDataPoints}
              chartType={dato.chartType || "line"}
              unit={dato.unit}
              item={dato}
              lang={lang}
            />
          </section>

          {/* 3. Trazabilidad y Fuentes Oficiales */}
          <section>
            <SourceCard
              sources={dato.sources}
              lastUpdated={dato.sources?.[0]?.lastUpdated || dato.last_updated}
            />
          </section>
        </article>
      )}
    </div>
  );
}

import fs from "node:fs";
import path from "node:path";
import DatoClientView from "./DatoClientView";

interface PageProps {
  params: Promise<{ slug: string }>;
}

export async function generateStaticParams() {
  try {
    const itemsPath = path.join(process.cwd(), "data", "items.json");
    if (fs.existsSync(itemsPath)) {
      const items = JSON.parse(fs.readFileSync(itemsPath, "utf-8"));
      if (Array.isArray(items) && items.length > 0) {
        return items.map((item: { id: string }) => ({ slug: item.id }));

  return [{ slug: "_none" }];

function formatLabel(slug: string): string {
  if (ITEM_LABELS[slug]) return ITEM_LABELS[slug];
  return slug
    .split("-")
    .map((w) => w.charAt(0).toUpperCase() + w.slice(1))
    .join(" ");
}

function formatSpanishNumber(val: number): string {
  if (Math.abs(val) >= 1_000_000) {
    return `${(val / 1_000_000).toLocaleString("es-ES", { maximumFractionDigits: 2 })}M`;
  }
  return val.toLocaleString("es-ES");
}

function CustomFiscalTooltip({ active, payload, label, fiscalTab }: any) {
  if (!active || !payload || !payload.length) return null;

  return (
    <div className="bg-slate-900 text-white p-3.5 rounded-xl shadow-xl border border-slate-700 text-xs max-w-xs space-y-2">
      <div className="flex items-center justify-between border-b border-slate-800 pb-2 font-bold">
        <span>Año {label}</span>
        <span className="text-blue-400 font-semibold">
          {fiscalTab === "ratio"
            ? "Ratio Contribución/Gasto"
            : fiscalTab === "capita"
            ? "Saldo Neto (€/hab)"
            : "Balance Total Estado (IGAE S.13)"}
        </span>
      </div>
      <div className="space-y-1.5 text-[11px]">
        {payload.map((entry: any, i: number) => {
          const labelText = formatLabel(entry.dataKey || entry.name);
          const val = Number(entry.value) || 0;
          let displayVal = "";
          if (fiscalTab === "ratio") {
            displayVal = `${val.toFixed(1)}% (${val >= 100 ? "Superávit" : "Déficit"})`;
          } else if (fiscalTab === "capita") {
            displayVal = `${val >= 0 ? "+" : ""}${val.toLocaleString("es-ES")} €/hab`;
          } else {
            displayVal = `${val.toLocaleString("es-ES")} MM€`;
          }

          return (
            <div key={i} className="flex items-center justify-between gap-3">
              <div className="flex items-center gap-1.5 truncate">
                <span
                  className="w-2.5 h-2.5 rounded-full flex-shrink-0"
                  style={{ backgroundColor: entry.color }}
                />
                <span className="truncate text-slate-300">{labelText}</span>
              </div>
              <span className="font-semibold text-white tabular-nums">
                {displayVal}
              </span>
            </div>
          );
        })}
      </div>
    </div>
  );
}

function CustomTooltipContent({ active, payload, label, unit }: any) {
  if (!active || !payload || !payload.length) return null;

  const total = payload.reduce(
    (sum: number, entry: any) => sum + (Number(entry.value) || 0),
    0
  );

  return (
    <div className="bg-slate-900 text-white p-3.5 rounded-xl shadow-xl border border-slate-700 text-xs max-w-xs space-y-2">
      <div className="flex items-center justify-between border-b border-slate-800 pb-2 font-bold">
        <span>Año {label}</span>
        <span className="text-blue-400 font-extrabold">
          {total.toLocaleString("es-ES")} {unit}
        </span>
      </div>
      <div className="space-y-1.5 max-h-60 overflow-y-auto pr-1 text-[11px]">
        {payload
          .slice()
          .reverse()
          .map((entry: any, i: number) => {
            const labelText = formatLabel(entry.dataKey || entry.name);
            const val = Number(entry.value) || 0;

            return (
              <div key={i} className="flex items-center justify-between gap-3">
                <div className="flex items-center gap-1.5 truncate">
                  <span
                    className="w-2.5 h-2.5 rounded-full flex-shrink-0"
                    style={{ backgroundColor: entry.color }}
                  />
                  <span className="truncate text-slate-300">{labelText}</span>
                </div>
                <span className="font-semibold text-white tabular-nums">
                  {val.toLocaleString("es-ES")} {unit}
                </span>
              </div>
            );
          })}
      </div>
    </div>
  );
}

interface SourceCardProps extends TraceableSource {
  lastUpdated?: string;
  defaultInstitution?: string;
  description?: string;
}

const DEFAULT_INSTITUTION = "Instituto Nacional de Estadística (INE)";

function normalizeSources(source?: SourceInfo, sources?: SourceInfo[]): SourceInfo[] {
  if (sources && sources.length > 0) return sources;
  if (source) return [source];
  return [];
}

function resolveShortName(source: SourceInfo): string {
  return source.shortName || source.title || source.institution || "Ver fuente oficial";
}

function buildSourceKey(source: SourceInfo, fallbackIdx: number): string {
  return `${source.tableId ?? "src"}-${source.period ?? fallbackIdx}-${source.url}`;
}

export default function SourceCard({

  africa: "África",
  asia: "Asia",
  oceania: "Oceanía",
};

function truncateCountryName(name: string, maxLen = 11): string {
  if (name.length <= maxLen) return name;
  return name.slice(0, maxLen - 1).trim() + "…";
}

          color: block.color,
        });

    });

            {selectedTimeframeLabel} • {lang === "en" ? "Interactive geographic breakdown and detailed origin ranking." : "Desglose geográfico interactivo y ranking detallado de origen."}

          >

        {/* LEFT PANEL: Single-Ring Continent Donut + Vertical Breakdown List (5 columns) */}

"use client";

import { useState, useMemo, useEffect } from "react";
import { ImmigrationItem, AnnualBlock } from "@/types";
import WebGisChronoArcs from "./WebGisChronoArcs";
import TimelineScrubber from "./TimelineScrubber";
import ContinentCountrySplitView from "./ContinentCountrySplitView";
import { Lang } from "@/lib/i18n";

type TimeframeMode = "single" | "range";
type YearRange = [string, string];

const PLAYBACK_INTERVAL_MS = 900;
const DEFAULT_FALLBACK_END_YEAR = "2024";
const DEFAULT_FALLBACK_START_YEAR = "2019";
const DEFAULT_RANGE_SPAN = 5;

interface ImmigrationViewProps {
  item: ImmigrationItem;
  lang?: Lang;
}

interface AggregatedMetrics {
  activeDataMap: Record<string, number>;
  totalArrivals: number;
  timeframeLabel: string;
}

function aggregateAnnualBlocks(blocks: AnnualBlock[]): {
  dataMap: Record<string, number>;
  total: number;
} {
  const dataMap: Record<string, number> = {};
  let total = 0;

  for (const annualBlock of blocks) {
    total += annualBlock.total;
    for (const regionalBlock of Object.values(annualBlock.blocks)) {
      for (const [countryId, volume] of Object.entries(regionalBlock.countries)) {
        dataMap[countryId] = (dataMap[countryId] ?? 0) + volume;
      }
    }
  }

  return { dataMap, total };
}

export default function ImmigrationView({ item, lang = "es" }: ImmigrationViewProps) {
  const years = useMemo(
    () => item.annualBlocks.map((block) => block.year),
    [item.annualBlocks]
  );

  const latestYear = years.at(-1) ?? DEFAULT_FALLBACK_END_YEAR;
  const defaultRangeStart =
    years[Math.max(0, years.length - DEFAULT_RANGE_SPAN)] ?? DEFAULT_FALLBACK_START_YEAR;

  const [selectedYear, setSelectedYear] = useState<string>(latestYear);
  const [yearRange, setYearRange] = useState<YearRange>([defaultRangeStart, latestYear]);
  const [mode, setMode] = useState<TimeframeMode>("single");
  const [isPlaying, setIsPlaying] = useState<boolean>(false);

  const [hoveredCountryId, setHoveredCountryId] = useState<string | null>(null);
  const [pinnedCountryId, setPinnedCountryId] = useState<string | null>(null);
  const [searchQuery, setSearchQuery] = useState<string>("");
  const [selectedBlockFilter, setSelectedBlockFilter] = useState<string>("");
  const [minVolumeThreshold, setMinVolumeThreshold] = useState<number>(0);

  // Stop playback when reaching the end of the timeline without triggering impure state updates inside setSelectedYear
  useEffect(() => {
    if (!isPlaying || mode !== "single") return;

    const currentIdx = years.indexOf(selectedYear);
    if (currentIdx === -1 || currentIdx >= years.length - 1) {
      setIsPlaying(false);
      return;
    }

    const timer = window.setTimeout(() => {
      setSelectedYear(years[currentIdx + 1]);
    }, PLAYBACK_INTERVAL_MS);

    return () => window.clearTimeout(timer);
  }, [isPlaying, mode, selectedYear, years]);

  const { activeDataMap, totalArrivals, timeframeLabel } = useMemo<AggregatedMetrics>(() => {
    if (mode === "single") {
      const targetBlock = item.annualBlocks.find((d) => d.year === selectedYear);
      const { dataMap, total } = aggregateAnnualBlocks(targetBlock ? [targetBlock] : []);
      return {
        activeDataMap: dataMap,
        totalArrivals: total,
        timeframeLabel: `Año ${selectedYear}`,
      };
    }

    const startIdx = years.indexOf(yearRange[0]);
    const endIdx = years.indexOf(yearRange[1]);

    const matchingBlocks =
      startIdx !== -1 && endIdx !== -1
        ? item.annualBlocks.filter((ab) => {
            const yIdx = years.indexOf(ab.year);
            return yIdx >= Math.min(startIdx, endIdx) && yIdx <= Math.max(startIdx, endIdx);
          })
        : [];

    const { dataMap, total } = aggregateAnnualBlocks(matchingBlocks);

    return {
      activeDataMap: dataMap,
      totalArrivals: total,
      timeframeLabel: `Rango ${yearRange[0]}–${yearRange[1]}`,
    };
  }, [item.annualBlocks, mode, selectedYear, yearRange, years]);

  return (
    <div className="space-y-6">
      {/* Top Timeline Scrubber (Placed right at the top) */}
      <TimelineScrubber
        years={years}
        selectedYear={selectedYear}
        setSelectedYear={setSelectedYear}
        yearRange={yearRange}
        setYearRange={setYearRange}
        mode={mode}
        setMode={setMode}
        isPlaying={isPlaying}
        setIsPlaying={setIsPlaying}
      />

      {/* 1. Map Canvas */}
      <div className="w-full">
        <WebGisChronoArcs
          timeframeLabel={timeframeLabel}
          activeDataMap={activeDataMap}
          totalArrivals={totalArrivals}
          hoveredCountryId={hoveredCountryId}
          setHoveredCountryId={setHoveredCountryId}
          pinnedCountryId={pinnedCountryId}
          setPinnedCountryId={setPinnedCountryId}
          searchQuery={searchQuery}
          selectedBlockFilter={selectedBlockFilter}
          minVolumeThreshold={minVolumeThreshold}
        />
      </div>

      {/* 2. Continent Donut & Country Ranking Split View */}
      <ContinentCountrySplitView
        item={item}
        activeDataMap={activeDataMap}
        totalArrivals={totalArrivals}
        pinnedCountryId={pinnedCountryId}
        setPinnedCountryId={setPinnedCountryId}
        hoveredCountryId={hoveredCountryId}
        setHoveredCountryId={setHoveredCountryId}
        selectedTimeframeLabel={timeframeLabel}
        lang={lang}
      />
    </div>
  );
}

            hoveredYear={hoveredYear}
            setHoveredYear={setHoveredYear}
            isolatedCountryId={isolatedCountryMap[block.id] || null}
            onToggleCountryIsolation={(cId) => toggleCountryIsolation(block.id, cId)}
          />
        ))}
      </div>
    </div>
  );
}

interface ContinentCardProps {
  item: ImmigrationItem;
  block: BlockDef;
  years: string[];
  scaleMode: "shared" | "independent";
  yMax: number;
  isZoomed: boolean;
  onToggleZoom: () => void;
  hoveredYear: string | null;
  setHoveredYear: (y: string | null) => void;
  isolatedCountryId: string | null;
  onToggleCountryIsolation: (countryId: string) => void;
}

function ContinentCard({
  item,
  block,
  years,
  scaleMode,
  yMax,
  isZoomed,
  onToggleZoom,
  hoveredYear,
  setHoveredYear,
  isolatedCountryId,
  onToggleCountryIsolation,
}: ContinentCardProps) {
  const width = 500;
  const height = 240;
  const margin = { top: 20, right: 15, bottom: 30, left: 45 };

  const innerW = width - margin.left - margin.right;
  const innerH = height - margin.top - margin.bottom;

  // Extract country data points over years
  const countrySeriesList = useMemo(() => {
    return block.countries.map((c) => {
      const points = item.annualBlocks.map((ab) => {
        const bData = ab.blocks[block.id];
        const val = bData?.countries[c.id] || 0;
        return { year: ab.year, value: val };
      });
      return {
        id: c.id,
        name: c.name,
        color: getCountryColor(c.id, block.color),
        points,
      };
    });
  }, [item, block]);

  // Compute stacked polygon paths
  const stackedData = useMemo(() => {
    // For each year i, calculate stacked Y positions
    const numYears = years.length;
    const numCountries = countrySeriesList.length;

    // stackedPoints[countryIdx][yearIdx] = { y0, y1 }
    const stackedPoints: Array<Array<{ y0: number; y1: number }>> = countrySeriesList.map(
      () => []
    );

    for (let yi = 0; yi < numYears; yi++) {
      let currentY = 0;
      for (let ci = 0; ci < numCountries; ci++) {
        const val = countrySeriesList[ci].points[yi].value;
        const y0 = currentY;
        const y1 = currentY + val;
        stackedPoints[ci].push({ y0, y1 });
        currentY = y1;
      }
    }

    // Convert to SVG paths
    const getX = (yearIdx: number) =>
      margin.left + (yearIdx / (numYears - 1)) * innerW;
    const getY = (val: number) =>
      margin.top + innerH - (val / (yMax || 1)) * innerH;

    return countrySeriesList.map((c, ci) => {
      const topCoords: string[] = [];
      const bottomCoords: string[] = [];

      for (let yi = 0; yi < numYears; yi++) {
        const x = getX(yi);
        const { y0, y1 } = stackedPoints[ci][yi];
        topCoords.push(`${x},${getY(y1)}`);
        bottomCoords.unshift(`${x},${getY(y0)}`);
      }

      const pathD = `M ${topCoords.join(" L ")} L ${bottomCoords.join(" L ")} Z`;
      return {
        ...c,
        pathD,
      };
    });
  }, [countrySeriesList, years, innerW, innerH, margin, yMax]);

  // Determine year under hover
  const activeYearData = useMemo(() => {
    const activeY = hoveredYear || years[years.length - 1];
    const ab = item.annualBlocks.find((d) => d.year === activeY);
    if (!ab) return null;

    const bData = ab.blocks[block.id];
    if (!bData) return null;

    const countryList = block.countries
      .map((c) => {
        const val = bData.countries[c.id] || 0;
        const pct = bData.total > 0 ? (val / bData.total) * 100 : 0;
        return {
          id: c.id,
          name: c.name,
          color: getCountryColor(c.id, block.color),
          value: val,
          pct,
        };
      })
      .sort((a, b) => b.value - a.value);

    return {
      year: activeY,
      total: bData.total,
      countries: countryList,
    };
  }, [item, block, years, hoveredYear]);

  // Calculate guide line X position
  const hoveredYearX = useMemo(() => {
    if (!hoveredYear) return null;
    const idx = years.indexOf(hoveredYear);
    if (idx === -1) return null;
    return margin.left + (idx / (years.length - 1)) * innerW;
  }, [hoveredYear, years, innerW, margin]);

  // Y-axis tick marks
  const yTicks = useMemo(() => {
    const count = 4;
    const ticks = [];
    for (let i = 0; i <= count; i++) {
      const val = (yMax / count) * i;
      ticks.push(val);
    }
    return ticks;
  }, [yMax]);

  return (
    <div className="bg-white border border-slate-200 rounded-2xl p-4 flex flex-col justify-between shadow-xs hover:shadow-md transition-shadow">
      {/* Card Header */}
      <div className="flex items-center justify-between pb-3 border-b border-slate-100">
        <div className="flex items-center gap-2">
          <span
            className="w-3 h-3 rounded-full shadow-xs"
            style={{ backgroundColor: block.color }}
          />
          <h3 className="text-sm font-bold text-slate-900 tracking-tight">
            {block.name}
          </h3>
        </div>

        <button
          onClick={onToggleZoom}
          title={isZoomed ? "Restaurar cuadrícula" : "Expandir continente"}
          className="p-1.5 text-slate-600 hover:text-slate-900 bg-slate-100 hover:bg-slate-200 rounded-lg transition-colors"
        >
          {isZoomed ? (
            <Minimize2 className="w-3.5 h-3.5" />
          ) : (
            <Maximize2 className="w-3.5 h-3.5" />
          )}
        </button>
      </div>

      {/* Main SVG Area Chart */}
      <div className="relative my-3" style={{ height: "220px" }}>
        <svg
          viewBox={`0 0 ${width} ${height}`}
          className="w-full h-full overflow-visible"
          onMouseLeave={() => setHoveredYear(null)}
          onMouseMove={(e) => {
            const rect = e.currentTarget.getBoundingClientRect();
            const mouseX = e.clientX - rect.left;
            const svgX = (mouseX / rect.width) * width;

            // Find closest year
            let closestYear = years[0];
            let minDiff = Infinity;
            years.forEach((y, idx) => {
              const yearX = margin.left + (idx / (years.length - 1)) * innerW;
              const diff = Math.abs(svgX - yearX);
              if (diff < minDiff) {
                minDiff = diff;
                closestYear = y;
              }
            });
            setHoveredYear(closestYear);
          }}
        >
          {/* Y Axis Grid Lines */}
          {yTicks.map((tick, i) => {
            const yPos = margin.top + innerH - (tick / yMax) * innerH;
            return (
              <g key={i}>
                <line
                  x1={margin.left}
                  y1={yPos}
                  x2={width - margin.right}
                  y2={yPos}
                  stroke="#F1F5F9"
                  strokeWidth="1"
                  strokeDasharray={i === 0 ? "none" : "3,3"}
                />
                <text
                  x={margin.left - 6}
                  y={yPos + 3}
                  textAnchor="end"
                  className="text-[10px] fill-slate-500 font-medium"
                >
                  {formatCompactSpanish(tick)}
                </text>
              </g>
            );
          })}

          {/* Stacked Area Layers */}
          {stackedData.map((layer) => {
            const isIsolated = isolatedCountryId === layer.id;
            const isDimmed = isolatedCountryId !== null && !isIsolated;

            return (
              <path
                key={layer.id}
                d={layer.pathD}
                fill={layer.color}
                fillOpacity={isIsolated ? 0.95 : isDimmed ? 0.15 : 0.75}
                stroke={layer.color}
                strokeWidth={isIsolated ? 2 : 1}
                className="transition-all duration-200 cursor-pointer"
                onClick={() => onToggleCountryIsolation(layer.id)}
              >
                <title>{layer.name}</title>
              </path>
            );
          })}

          {/* X Axis Labels */}
          {years.map((y, idx) => {
            if (idx % 3 !== 0 && idx !== years.length - 1) return null;
            const xPos = margin.left + (idx / (years.length - 1)) * innerW;
            return (
              <text
                key={y}
                x={xPos}
                y={height - 8}
                textAnchor="middle"
                className="text-[10px] fill-slate-500 font-medium"
              >
                {y}
              </text>
            );
          })}

          {/* Hover Line */}
          {hoveredYearX !== null && (
            <line
              x1={hoveredYearX}
              y1={margin.top}
              x2={hoveredYearX}
              y2={margin.top + innerH}
              stroke="#0F172A"
              strokeWidth="1.5"
              strokeDasharray="4,4"
              className="pointer-events-none"
            />
          )}
        </svg>

        {/* Floating Tooltip when Hovered */}
        {activeYearData && hoveredYear && (
          <div className="absolute top-2 right-2 bg-slate-900/95 text-white text-[11px] rounded-lg p-2.5 shadow-lg backdrop-blur-xs max-w-[210px] pointer-events-none z-10 space-y-1.5 animate-in fade-in duration-150">
            <div className="flex items-center justify-between font-bold border-b border-slate-700/80 pb-1">
              <span>Año {activeYearData.year}</span>
              <span className="text-blue-300">
                {formatSpanishNumber(activeYearData.total)}
              </span>
            </div>
            <div className="space-y-1 max-h-36 overflow-y-auto">
              {activeYearData.countries.map((c) => (
                <div
                  key={c.id}
                  className={`flex items-center justify-between gap-2 text-[10px] ${
                    isolatedCountryId === c.id
                      ? "font-bold text-yellow-300"
                      : "text-slate-300"
                  }`}
                >
                  <span className="truncate flex items-center gap-1">
                    <span
                      className="w-1.5 h-1.5 rounded-full flex-shrink-0"
                      style={{ backgroundColor: c.color }}
                    />
                    {c.name}
                  </span>
                  <span className="flex-shrink-0 font-mono">
                    {formatSpanishNumber(c.value)} ({c.pct.toFixed(1)}%)
                  </span>
                </div>
              ))}
            </div>
          </div>
        )}
      </div>

      {/* Interactive Legend for Country Isolation */}
      <div className="pt-3 border-t border-slate-100 flex flex-wrap gap-1.5 text-[11px]">
        {block.countries.map((c) => {
          const color = getCountryColor(c.id, block.color);
          const isIsolated = isolatedCountryId === c.id;
          const isDimmed = isolatedCountryId !== null && !isIsolated;

          return (
            <button
              key={c.id}
              onClick={() => onToggleCountryIsolation(c.id)}
              className={`px-2 py-0.5 rounded-md font-medium transition-all flex items-center gap-1 text-left ${
                isIsolated
                  ? "bg-slate-900 text-white shadow-xs font-bold ring-2 ring-offset-1 ring-slate-900"
                  : isDimmed
                  ? "bg-slate-50 text-slate-500 opacity-40 hover:opacity-100 border border-slate-200"
                  : "bg-slate-100 text-slate-700 hover:bg-slate-200"
              }`}
            >
              <span
                className="w-2 h-2 rounded-full flex-shrink-0"
                style={{ backgroundColor: color }}
              />
              <span className="truncate max-w-[120px]">{c.name}</span>
            </button>
          );
        })}
      </div>
    </div>
  );
}

"use client";

import { useState, useMemo, useEffect, useRef } from "react";
import {
  ImmigrationItem,
  BlockDef,
  getCountryColor,
  formatSpanishNumber,
  formatCompactSpanish,
  describeArc,
} from "./utils";
import {
  Play,
  Pause,
  Sparkles,
  XCircle,
} from "lucide-react";

interface SunburstViewProps {
  item: ImmigrationItem;
}

export default function SunburstView({ item }: SunburstViewProps) {
  const years = useMemo(() => item.annualBlocks.map((d) => d.year), [item]);
  const [selectedYear, setSelectedYear] = useState<string>(
    years[years.length - 1] || "2024"
  );
  const [isPlaying, setIsPlaying] = useState<boolean>(false);
  const [hoveredSector, setHoveredSector] = useState<{
    type: "block" | "country";
    name: string;
    value: number;
    globalPct: number;
    parentPct?: number;
    color: string;
  } | null>(null);

  const [activeDrillDownBlockId, setActiveDrillDownBlockId] = useState<
    string | null
  >(null);

  // Playback timer
  useEffect(() => {
    let timer: NodeJS.Timeout | null = null;
    if (isPlaying) {
      timer = setInterval(() => {
        setSelectedYear((prev) => {
          const currentIdx = years.indexOf(prev);
          if (currentIdx >= years.length - 1) {
            setIsPlaying(false);
            return prev;
          }
          return years[currentIdx + 1];
        });
      }, 800);
    }
    return () => {
      if (timer) clearInterval(timer);
    };
  }, [isPlaying, years]);

  // Active annual data
  const activeAnnualData = useMemo(() => {
    return (
      item.annualBlocks.find((d) => d.year === selectedYear) ||
      item.annualBlocks[item.annualBlocks.length - 1]
    );
  }, [item, selectedYear]);

  // Previous year data for YoY % calculation
  const prevYearData = useMemo(() => {
    const idx = years.indexOf(selectedYear);
    if (idx <= 0) return null;
    const prevY = years[idx - 1];
    return item.annualBlocks.find((d) => d.year === prevY) || null;
  }, [item, selectedYear, years]);

  // Calculate YoY % change
  const yoyPct = useMemo(() => {
    if (!prevYearData || prevYearData.total === 0) return null;
    const change = activeAnnualData.total - prevYearData.total;
    return (change / prevYearData.total) * 100;
  }, [activeAnnualData, prevYearData]);

  // Sunburst geometry calculations
  const { blockSectors, countrySectors } = useMemo(() => {
    const totalGlobal = activeAnnualData.total || 1;
    const cx = 250;
    const cy = 250;
    const rInBlock = 80;
    const rOutBlock = 145;
    const rInCountry = 152;
    const rOutCountry = 215;

    let currentAngle = -Math.PI / 2; // Start at 12 o'clock

    // If drilled down to a single continent
    const blocksToRender = activeDrillDownBlockId
      ? item.blocks.filter((b) => b.id === activeDrillDownBlockId)
      : item.blocks;

    const totalToDistribute = blocksToRender.reduce(
      (acc, b) => acc + (activeAnnualData.blocks[b.id]?.total || 0),
      0
    );

    const bSectors: any[] = [];
    const cSectors: any[] = [];

    blocksToRender.forEach((block) => {
      const bData = activeAnnualData.blocks[block.id];
      const bTotal = bData?.total || 0;
      if (bTotal === 0) return;

      const angleSpan = (bTotal / (totalToDistribute || 1)) * (2 * Math.PI);
      const startAngle = currentAngle;
      const endAngle = currentAngle + angleSpan;

      const pathD = describeArc(
        cx,
        cy,
        rInBlock,
        rOutBlock,
        startAngle,
        endAngle
      );
      const globalPct = (bTotal / totalGlobal) * 100;

      bSectors.push({
        id: block.id,
        name: block.name,
        color: block.color,
        value: bTotal,
        globalPct,
        startAngle,
        endAngle,
        pathD,
      });

      // Calculate country sub-arcs aligned with block arc
      let cCurrentAngle = startAngle;
      block.countries.forEach((country) => {
        const cVal = bData?.countries[country.id] || 0;
        if (cVal === 0) return;

        const cAngleSpan = (cVal / (bTotal || 1)) * angleSpan;
        const cStartAngle = cCurrentAngle;
        const cEndAngle = cCurrentAngle + cAngleSpan;

        const cPathD = describeArc(
          cx,
          cy,
          rInCountry,
          rOutCountry,
          cStartAngle,
          cEndAngle
        );

        const cGlobalPct = (cVal / totalGlobal) * 100;
        const cParentPct = (cVal / bTotal) * 100;
        const cColor = getCountryColor(country.id, block.color);

        cSectors.push({
          id: country.id,
          name: country.name,
          blockId: block.id,
          blockName: block.name,
          color: cColor,
          value: cVal,
          globalPct: cGlobalPct,
          parentPct: cParentPct,
          startAngle: cStartAngle,
          endAngle: cEndAngle,
          pathD: cPathD,
        });

        cCurrentAngle = cEndAngle;
      });

      currentAngle = endAngle;
    });

    return { blockSectors: bSectors, countrySectors: cSectors };
  }, [item, activeAnnualData, activeDrillDownBlockId]);

  // Global sparkline points
  const sparklineData = useMemo(() => {
    const maxVal = Math.max(...item.annualBlocks.map((d) => d.total));
    const width = 200;
    const height = 36;
    const pts = item.annualBlocks.map((ab, idx) => {
      const x = (idx / (item.annualBlocks.length - 1)) * width;
      const y = height - (ab.total / (maxVal || 1)) * (height - 6) - 3;
      return { x, y, year: ab.year, total: ab.total };
    });

    const activePt = pts.find((p) => p.year === selectedYear);
    const pathD = `M ${pts.map((p) => `${p.x},${p.y}`).join(" L ")}`;

    return { pts, pathD, activePt, width, height };
  }, [item, selectedYear]);

  // Milestone quick access years
  const keyMilestones = [
    { year: "2008", label: "2008 (Inicio)" },
    { year: "2013", label: "2013 (Valle)" },
    { year: "2019", label: "2019 (Pre-COVID)" },
    { year: "2020", label: "2020 (COVID-19)" },
    { year: "2022", label: "2022 (Pico UE)" },
    { year: "2024", label: "2024 (Último)" },
  ];

  return (
    <div className="space-y-6">
      {/* Top Bar: Playback Controls & Sparkline */}
      <div className="bg-slate-50 border border-slate-200 rounded-2xl p-4 sm:p-5 flex flex-col md:flex-row items-stretch md:items-center justify-between gap-6">
        {/* Play/Pause & Slider */}
        <div className="flex-1 space-y-3">
          <div className="flex items-center justify-between">
            <div className="flex items-center gap-3">
              <button
                onClick={() => setIsPlaying(!isPlaying)}
                className="w-10 h-10 rounded-full bg-blue-600 hover:bg-blue-700 text-white flex items-center justify-center shadow-md transition-all active:scale-95"
                title={isPlaying ? "Pausar animación" : "Reproducir serie"}
              >
                {isPlaying ? (
                  <Pause className="w-5 h-5 fill-current" />
                ) : (
                  <Play className="w-5 h-5 fill-current ml-0.5" />
                )}
              </button>
              <div>
                <span className="text-xs font-semibold text-slate-500 uppercase tracking-wider block">
                  Año Seleccionado
                </span>
                <span className="text-xl font-extrabold text-slate-900 font-mono">
                  {selectedYear}
                </span>
              </div>
            </div>

            {/* Drilldown Reset Button */}
            {activeDrillDownBlockId && (
              <button
                onClick={() => setActiveDrillDownBlockId(null)}
                className="px-3 py-1.5 rounded-lg text-xs font-bold bg-amber-100 hover:bg-amber-200 text-amber-800 transition-colors flex items-center gap-1.5"
              >
                <XCircle className="w-4 h-4" />
                Ver todos los continentes
              </button>
            )}
          </div>

          {/* Slider */}
          <input
            type="range"
            min="2008"
            max="2024"
            step="1"
            value={selectedYear}
            onChange={(e) => {
              setIsPlaying(false);
              setSelectedYear(e.target.value);
            }}
            className="w-full h-2.5 bg-slate-200 rounded-lg appearance-none cursor-pointer accent-blue-600"
          />

          {/* All Years Quick Access Buttons */}
          <div className="flex flex-wrap gap-1.5 pt-1">
            {years.map((y) => (
              <button
                key={y}
                onClick={() => {
                  setIsPlaying(false);
                  setSelectedYear(y);
                }}
                className={`px-2.5 py-1 rounded-md text-[11px] font-semibold transition-all ${
                  selectedYear === y
                    ? "bg-slate-900 text-white shadow-xs font-bold"
                    : "bg-white text-slate-600 hover:bg-slate-100 border border-slate-200"
                }`}
              >
                {y}
              </button>
            ))}
          </div>
        </div>

        {/* Mini Sparkline Context Graph */}
        <div className="bg-white border border-slate-200 rounded-xl p-3 flex flex-col justify-between min-w-[220px]">
          <div className="flex items-center justify-between text-xs mb-1">
            <span className="font-semibold text-slate-500 flex items-center gap-1">
              <Sparkles className="w-3.5 h-3.5 text-blue-600" />
              Tendencia Global (2008–2024)
            </span>
            <span className="font-bold font-mono text-slate-900">
              {formatCompactSpanish(activeAnnualData.total)}
            </span>
          </div>
          <svg
            viewBox={`0 0 ${sparklineData.width} ${sparklineData.height}`}
            className="w-full h-9 overflow-visible"
          >
            <path
              d={sparklineData.pathD}
              fill="none"
              stroke="#94A3B8"
              strokeWidth="2"
              strokeLinecap="round"
            />
            {sparklineData.activePt && (
              <circle
                cx={sparklineData.activePt.x}
                cy={sparklineData.activePt.y}
                r="4"
                className="fill-blue-600 stroke-white stroke-2 animate-pulse"
              />
            )}
          </svg>
        </div>
      </div>

      {/* Main Container: Sunburst Graphic Centered */}
      <div className="flex flex-col items-center justify-center bg-white border border-slate-200 rounded-2xl p-6 sm:p-8 shadow-xs">
        {/* Sunburst SVG */}
        <div className="w-full max-w-[500px] flex flex-col items-center justify-center relative">
          <div className="relative w-full aspect-square">
            <svg
              viewBox="0 0 500 500"
              className="w-full h-full overflow-visible drop-shadow-xs"
            >
              {/* Inner Ring (Continents) */}

                const isHovered =
                  hoveredSector?.name === sector.name &&
                  hoveredSector?.type === "block";
                return (

                      setHoveredSector({

              })}

              {/* Outer Ring (Countries) */}
              {countrySectors.map((sector) => {
                const isHovered =
                  hoveredSector?.name === sector.name &&
                  hoveredSector?.type === "country";
                return (
                  <path

                    d={sector.pathD}
                    fill={sector.color}
                    fillOpacity={isHovered ? 1 : 0.82}
                    stroke="#FFFFFF"
                    strokeWidth="1.5"
                    className="cursor-pointer transition-all duration-200 hover:scale-[1.02] origin-center"
                    onMouseEnter={() =>
                      setHoveredSector({
                        type: "country",
                        name: sector.name,
                        value: sector.value,
                        globalPct: sector.globalPct,
                        parentPct: sector.parentPct,
                        color: sector.color,
                      })
                    }
                    onMouseLeave={() => setHoveredSector(null)}
                  >
                    <title>

// Jenks Natural Breaks Algorithm Implementation in TypeScript
export function getJenksBreaks(data: number[], numClasses: number): number[] {
  if (!data || data.length === 0) return [];
  const sorted = [...data].sort((a, b) => a - b);
  const n = sorted.length;
  if (numClasses >= n) {
    return [...new Set(sorted)];
  }

  const mat1 = Array(n + 1).fill(0).map(() => Array(numClasses + 1).fill(0));
  const mat2 = Array(n + 1).fill(0).map(() => Array(numClasses + 1).fill(0));

  for (let i = 1; i <= numClasses; i++) {
    mat1[1][i] = 1;
    mat2[1][i] = 0;
    for (let j = 2; j <= n; j++) {
      mat2[j][i] = Infinity;
    }
  }

  let variance = 0;
  for (let l = 2; l <= n; l++) {
    let sum = 0;
    let sumSquares = 0;
    let w = 0;
    for (let m = 1; m <= l; m++) {
      const val = sorted[l - m];
      w++;
      sum += val;
      sumSquares += val * val;
      variance = sumSquares - (sum * sum) / w;
      const i4 = l - m;
      if (i4 !== 0) {
        for (let j = 2; j <= numClasses; j++) {
          if (mat2[l][j] >= (variance + mat2[i4][j - 1])) {
            mat1[l][j] = i4;
            mat2[l][j] = variance + mat2[i4][j - 1];
          }
        }
      }
    }
    mat1[l][1] = 1;
    mat2[l][1] = variance;
  }

  let k = n;
  const kclass = Array(numClasses + 1).fill(0);
  kclass[numClasses] = sorted[n - 1];
  kclass[0] = sorted[0];

  let countNum = numClasses;
  while (countNum >= 2) {
    const idx = Math.round(mat1[k][countNum]);
    kclass[countNum - 1] = sorted[idx - 1];
    k = idx;
    countNum--;
  }

  // Extract unique threshold cut points
  const breaks = [];
  for (let i = 1; i < kclass.length; i++) {
    breaks.push(kclass[i]);
  }
  return Array.from(new Set(breaks)).sort((a, b) => a - b);
}

// Convert angle to SVG arc path
export function describeArc(
  cx: number,
  cy: number,
  rIn: number,
  rOut: number,
  startAngleRad: number,
  endAngleRad: number
): string {
  let delta = endAngleRad - startAngleRad;
  if (delta < 0.0001) return "";
  if (delta >= 2 * Math.PI) {
    delta = 2 * Math.PI - 0.0001;
    endAngleRad = startAngleRad + delta;
  }

  const x1Outer = cx + rOut * Math.cos(startAngleRad);
  const y1Outer = cy + rOut * Math.sin(startAngleRad);
  const x2Outer = cx + rOut * Math.cos(endAngleRad);
  const y2Outer = cy + rOut * Math.sin(endAngleRad);

  const x1Inner = cx + rIn * Math.cos(startAngleRad);
  const y1Inner = cy + rIn * Math.sin(startAngleRad);
  const x2Inner = cx + rIn * Math.cos(endAngleRad);
  const y2Inner = cy + rIn * Math.sin(endAngleRad);

  const largeArcFlag = delta > Math.PI ? 1 : 0;

  return [
    `M ${x1Outer} ${y1Outer}`,
    `A ${rOut} ${rOut} 0 ${largeArcFlag} 1 ${x2Outer} ${y2Outer}`,
    `L ${x2Inner} ${y2Inner}`,
    `A ${rIn} ${rIn} 0 ${largeArcFlag} 0 ${x1Inner} ${y1Inner}`,
    "Z",
  ].join(" ");
}

// Robust Web-GIS Equirectangular / Miller Projection mapping [lng, lat] to SVG [x, y]
export function projectCoordinates(
  lng: number,
  lat: number,
  width: number,
  height: number,
  zoom = 1,
  panX = 0,
  panY = 0
): { x: number; y: number } {
  // Bounding box for Atlantic / Mediterranean Basin (Span: W -95 to E 45, S -45 to N 65)
  const minLng = -95;
  const maxLng = 45;
  const minLat = -45;
  const maxLat = 65;

  const mapSpanLng = maxLng - minLng;
  const mapSpanLat = maxLat - minLat;

  const xNorm = (lng - minLng) / mapSpanLng;
  const yNorm = (maxLat - lat) / mapSpanLat; // Inverted Y for SVG

  const baseScale = Math.max(width, height) * 1.25 * zoom;
  const offsetX = (width - baseScale) / 2 + panX;
  const offsetY = (height - (baseScale * (mapSpanLat / mapSpanLng))) / 2 + panY;

  const x = xNorm * baseScale * 0.95 + offsetX;
  const y = yNorm * (baseScale * 0.7) + offsetY;

  return { x, y };
}

// Generate smooth bundled Bézier path
export function generateBundledArcPath(
  x0: number,
  y0: number,
  xw: number,
  yw: number,
  x1: number,
  y1: number,
  bundleEnabled = true
): string {
  if (!bundleEnabled) {
    const dx = x1 - x0;
    const dy = y1 - y0;
    const cx = (x0 + x1) / 2 - dy * 0.2;
    const cy = (y0 + y1) / 2 + dx * 0.2;
    return `M ${x0} ${y0} Q ${cx} ${cy} ${x1} ${y1}`;
  }

  const ctrl1X = (x0 + xw) / 2;
  const ctrl1Y = (y0 + yw) / 2;
  const ctrl2X = (xw + x1) / 2;
  const ctrl2Y = (yw + y1) / 2;

  return `M ${x0} ${y0} Q ${ctrl1X} ${ctrl1Y} ${xw} ${yw} Q ${ctrl2X} ${ctrl2Y} ${x1} ${y1}`;
}

  if (ratio < 0.25) return "#eab308"; // Medio (Yellow)

  if (Math.abs(val) >= 1_000_000) {
    return `${(val / 1_000_000).toLocaleString("es-ES", { maximumFractionDigits: 2 })}M`;
  }
  if (Math.abs(val) >= 1_000) {
    return `${(val / 1_000).toLocaleString("es-ES", { maximumFractionDigits: 0 })}k`;
  }
  return Math.round(val).toLocaleString("es-ES");
}

export function getChoroplethCountryPolygons(
  width: number,
  height: number,
  zoom: number,
  panX: number,
  panY: number
): Array<{ featureId: string; countryId: string | null; name: string; pathD: string }> {
  const result: Array<{ featureId: string; countryId: string | null; name: string; pathD: string }> = [];
  const features = (countriesData as any).features || [];

  features.forEach((feature: any, fIdx: number) => {
    const props = feature.properties || {};
    const name = props.NAME || props.ADMIN || `Country_${fIdx}`;

    let matchedCountryId: string | null = null;
    if (name === "Spain" || name === "España") {
      matchedCountryId = "spain";
    } else {
      for (const [cId, namesList] of Object.entries(COUNTRY_NAME_MAPPING)) {
        if (namesList.includes(name) || namesList.includes(props.NAME_LONG)) {
          matchedCountryId = cId;
          break;
        }
      }
    }

    const geom = feature.geometry;
    if (!geom) return;

    const polygons: Array<Array<[number, number]>> = [];
    if (geom.type === "Polygon") {
      if (geom.coordinates && geom.coordinates[0]) {
        polygons.push(geom.coordinates[0]);
      }
    } else if (geom.type === "MultiPolygon") {
      geom.coordinates.forEach((polyCoords: Array<Array<[number, number]>>) => {
        if (polyCoords && polyCoords[0]) {
          polygons.push(polyCoords[0]);
        }
      });
    }

    polygons.forEach((ring) => {
      const coords: string[] = [];
      ring.forEach(([lng, lat]: [number, number], index: number) => {
        const pt = projectCoordinates(lng, lat, width, height, zoom, panX, panY);
        const cmd = index === 0 ? "M" : "L";
        coords.push(`${cmd} ${pt.x.toFixed(1)} ${pt.y.toFixed(1)}`);
      });

      if (coords.length > 2) {
        result.push({
          featureId: `${fIdx}_${Math.random()}`,
          countryId: matchedCountryId,
          name,
          pathD: `${coords.join(" ")} Z`,
        });
      }
    });
  });

  return result;
}

"use client";

import { useMemo } from "react";

interface SparklineProps {
  dataPoints: Array<{ year?: string; date?: string; value: any }>;
  width?: number;
  height?: number;
  color?: string;
}

export default function Sparkline({
  dataPoints,
  width = 110,
  height = 32,
  color = "#3B82F6",
}: SparklineProps) {
  const points = useMemo(() => {
    if (!Array.isArray(dataPoints) || dataPoints.length === 0) return [];

    const extracted = dataPoints.map((dp) => {
      let val = 0;
      const rawVal = dp.value;
      if (typeof rawVal === "number") {
        val = rawVal;
      } else if (Array.isArray(rawVal)) {
        const totalObj = rawVal.find((item: any) => item && typeof item === "object" && "total" in item) || rawVal[0];
        val = totalObj ? (Object.values(totalObj)[0] as number) : 0;
      }
      return val;
    });

    const min = Math.min(...extracted);
    const max = Math.max(...extracted);
    const range = max - min || 1;
    const padding = 4;
    const drawW = width - padding * 2;
    const drawH = height - padding * 2;

    return extracted.map((v, idx) => {
      const x = padding + (idx / (extracted.length - 1 || 1)) * drawW;
      const y = height - padding - ((v - min) / range) * drawH;
      return { x, y };
    });
  }, [dataPoints, width, height]);

  if (points.length < 2) return null;

  const pathD = `M ${points.map((p) => `${p.x.toFixed(1)},${p.y.toFixed(1)}`).join(" L ")}`;

  return (
    <svg width={width} height={height} className="overflow-visible shrink-0">
      <path
        d={pathD}
        fill="none"
        stroke={color}
        strokeWidth="2"
        strokeLinecap="round"
        strokeLinejoin="round"
      />
      <circle
        cx={points[points.length - 1].x}
        cy={points[points.length - 1].y}
        r="3"
        fill={color}
      />
    </svg>
  );
}

// Spanish Number Formatter with automatic compact abbreviations (MM, M, mil)

export function formatSpanishCompact(val: number): string {
  if (val === undefined || val === null || isNaN(val)) return "0";
  const abs = Math.abs(val);

  if (abs >= 1_000_000_000) {
    return `${(val / 1_000_000_000).toLocaleString("es-ES", { minimumFractionDigits: 2, maximumFractionDigits: 2 })} MM`;
  }
  if (abs >= 1_000_000) {
    return `${(val / 1_000_000).toLocaleString("es-ES", { minimumFractionDigits: 2, maximumFractionDigits: 2 })} M`;
  }
  if (abs >= 10_000) {
    return `${(val / 1_000).toLocaleString("es-ES", { minimumFractionDigits: 1, maximumFractionDigits: 1 })} mil`;
  }
  if (abs >= 1_000) {
    return val.toLocaleString("es-ES");
  }
  return val.toLocaleString("es-ES");
}

export function formatSpanishExact(val: number): string {
  if (val === undefined || val === null || isNaN(val)) return "0";
  return Math.round(val).toLocaleString("es-ES");
}

import { GlobalMetadata, DatoItem, ItemIndexItem, Category, SourceInfo } from "@/types";

export const DATA_BASE_URL =
  process.env.NEXT_PUBLIC_DATA_BASE_URL || "/data";

const cleanBaseUrl = DATA_BASE_URL.replace(/\/$/, "");

export async function fetchMetadata(lang: "es" | "en" = "es"): Promise<GlobalMetadata> {
  try {
    let res = await fetch(`${cleanBaseUrl}/${lang}/metadata.json`);
    if (!res.ok) {
      res = await fetch(`${cleanBaseUrl}/metadata.json`);
    }
    if (!res.ok) {
      return { last_updated: new Date().toISOString().split("T")[0], total_items: 0 };
    }
    return await res.json();
  } catch (err) {
    console.warn("Could not fetch metadata.json:", err);
    return { last_updated: new Date().toISOString().split("T")[0], total_items: 0 };
  }
}

export async function fetchItems(lang: "es" | "en" = "es"): Promise<ItemIndexItem[]> {
  try {
    let res = await fetch(`${cleanBaseUrl}/${lang}/items.json`);
    if (!res.ok) {
      res = await fetch(`${cleanBaseUrl}/items.json`);
    }
    if (!res.ok) {
      const fallbackRes = await fetch(`${cleanBaseUrl}/counties.json`);
      if (!fallbackRes.ok) return [];
      const counties = await fallbackRes.json();
      return counties.map((c: any) => ({
        id: c.id,
        category: "Economía y Empleo",
        question: c.name,
        unit: "",
        latestValue: c.latest_summary ? Object.values(c.latest_summary)[0] as number : 0,
        latestYear: "2026",
        lastUpdated: c.last_updated || "2026-11-01"
      }));
    }
    return await res.json();
  } catch (err) {
    console.warn("Could not fetch items index:", err);
    return [];
  }
}

export const fetchCounties = fetchItems;

export async function fetchItemDetail(id: string, lang: "es" | "en" = "es"): Promise<DatoItem | null> {
  try {
    let res = await fetch(`${cleanBaseUrl}/${lang}/items/${id}.json`);
    if (!res.ok && lang === "en") {
      // Automatic Fallback to Spanish if English translation is missing
      res = await fetch(`${cleanBaseUrl}/es/items/${id}.json`);
      if (!res.ok) {
        res = await fetch(`${cleanBaseUrl}/items/${id}.json`);
      }
    } else if (!res.ok) {
      res = await fetch(`${cleanBaseUrl}/items/${id}.json`);
    }
    if (!res.ok) {
      res = await fetch(`${cleanBaseUrl}/counties/${id}.json`);
    }
    if (!res.ok) return null;
    const raw = await res.json();

    const normalizeSourcesList = (r: any): SourceInfo[] => {
      if (Array.isArray(r.sources) && r.sources.length > 0) {
        return r.sources.map((s: any) => ({
          institution: s.institution || "Fuente Oficial",
          title: s.title || r.question || "Fuente Oficial de Datos",
          url: s.url || "#",
          shortName: s.shortName,
          tableId: s.tableId,
          period: s.period,
          lastUpdated: s.lastUpdated || r.last_updated || r.lastUpdated
        }));
      }
      if (r.source) {
        return [{
          institution: r.source.institution || "Fuente Oficial",
          title: r.source.title || r.question || "Fuente Oficial de Datos",
          url: r.source.url || "#",
          shortName: r.source.shortName,
          tableId: r.source.tableId,
          period: r.source.period,
          lastUpdated: r.source.lastUpdated || r.last_updated || r.lastUpdated
        }];
      }
      return [{
        institution: "Fuente Oficial",
        title: r.question || "Fuente Oficial de Datos",
        url: "#",
        lastUpdated: r.last_updated || r.lastUpdated
      }];
    };

    if (raw.metrics) {
      const metricKey = Object.keys(raw.metrics)[0];
      const metric = raw.metrics[metricKey];
      return {
        id: raw.county_id || raw.id,
        category: raw.category || "Economía y Empleo",
        question: raw.name || raw.question || metricKey,
        chartType: "line",
        unit: metric?.unit || raw.unit || "",
        dataPoints: (metric?.series || []).map((s: any) => ({
          year: s.date || s.year,
          value: s.value
        })),
        contextNotes: raw.contextNotes || [],
        sources: normalizeSourcesList(raw)
      };
    }

    return {
      ...raw,
      sources: normalizeSourcesList(raw)
    } as DatoItem;
  } catch (err) {
    console.warn(`Could not fetch item detail for ${id}:`, err);
    return null;
  }
}

    if (val >= 1e9) return (val / 1e9).toFixed(1) + "B";
    if (val >= 1e6) return (val / 1e6).toFixed(1) + "M";

# Diseño del Sistema y Especificación Técnica: Datos España

> **Propósito de este documento:** Servir como fuente única de verdad (*Single Source of Truth*) para cualquier agente de código o desarrollador que trabaje en este repositorio. Define la visión del producto, la arquitectura de datos sin base de datos, el motor de gráficos comparativos estilo Google Trends y las reglas estrictas de implementación.

---

## 1. Visión del Producto
**Datos España** es una plataforma web interactiva, minimalista y radicalmente neutral que funciona como un **"Google Trends de datos oficiales de España"**. 

Su objetivo es reducir la asimetría de información en debates públicos, mediáticos y políticos permitiendo a cualquier ciudadano buscar, cruzar y comparar series temporales históricas de fuentes oficiales (INE, SEPE, BOE, Banco de España, CIS, Idealista, etc.) en un mismo gráfico, con total trazabilidad hacia la fuente original.

### Principios Innegociables
1. **Neutralidad Radical:** Cero adjetivos valorativos en la interfaz o en las notas metodológicas. Se muestran datos oficiales y definiciones técnicas; el usuario saca sus propias conclusiones.
2. **Alcance Puramente Nacional:** Todas las métricas corresponden al agregado nacional de España (sin desglose por provincias ni municipios) para garantizar simplicidad, velocidad y consistencia entre series.
3. **Cero Mantenimiento en Producción (Static-First):** No existe base de datos ni backend dinámico en producción. Todo el sistema se alimenta de archivos JSON estáticos alojados en `./data`.
4. **Trazabilidad Total:** Cada serie dibujada en pantalla debe mostrar explícitamente su organismo emisor, fecha de última actualización, enlace directo a la fuente oficial y notas metodológicas.

---

## 2. Arquitectura de Datos y Pipeline de Ingesta

El sistema divide completamente la **ingesta de datos** (ejecutada en local por el creador una vez al mes) de la **capa de visualización** (web estática ultrarrápida).

```text
[ Fuentes Oficiales (INE, SEPE, BOE, Banco de España, Idealista) ]
                              │
                              ▼ (Ejecución manual 1x / mes en local)
               [ Scraper Python + Validación ]
                              │
                              ▼ (Escribe en ./staging y valida integridad)
                [ Carpeta ./data (JSON Estáticos) ]
                              │
                              ▼ (HTTP fetch dinámico vía DATA_BASE_URL)
           [ Frontend Web + Motor de Gráficos Comparativos ]
```

### Reglas del Pipeline Local (`./staging` -> `./data`)
1. **Aislamiento en Staging:** El scraper nunca escribe directamente en `./data`. Genera los archivos en `./staging`.
2. **Validación Obligatoria:** Antes de mover a `./data`, un script verifica que:
   - Todos los JSON parsean sin errores.
   - No existen valores `NaN`, `Infinity` ni fechas mal formateadas (formato estricto `YYYY-MM`).
   - Ninguna serie está vacía.
3. **Carga Dinámica vía HTTP (No Bundling):** El frontend **NUNCA** debe importar los JSON de `./data` mediante `import` estático en tiempo de compilación. Siempre debe obtenerlos mediante `fetch()` usando una variable de entorno configurable `NEXT_PUBLIC_DATA_BASE_URL` (o `VITE_DATA_BASE_URL`, con valor por defecto `/data`). Esto permite actualizar `./data` sin recompilar la web y migrar `./data` a un bucket (Cloudflare R2 / AWS S3) en el futuro cambiando solo una URL.

---

## 3. Estructura de `./data` y Contratos JSON

La carpeta `./data` está organizada por **métricas individuales** para que el frontend descargue únicamente los archivos JSON de las series que el usuario decida cruzar en ese momento.

## 4. Experiencia de Usuario (UX) y Funcionalidades Core

La interfaz sigue el modelo mental de **Google Trends** combinado con la estética editorial de **Our World in Data**.

### 4.1. Barra de Exploración y Cruce de Métricas (Header Interactivo)
- **Selector Multi-Métrica:** El usuario puede añadir entre **1 y 4 métricas simultáneas** en el lienzo.
- **Chips de Series Activas:** Cada métrica seleccionada se muestra como una tarjeta/chip superior con su nombre corto, unidad, organismo fuente, un punto de color identificativo (ej. `#1E40AF`, `#DC2626`, `#059669`, `#D97706`) y un botón `×` para quitarla.
- **Botón `+ Añadir métrica para comparar`:** Abre un buscador instantáneo con autocompletado y pestañas de filtro por categoría (`Economía`, `Empleo`, `Vivienda`, etc.) alimentado por `catalog.json`.
- **Presets / Comparativas Sugeridas (Estado Inicial):** Al entrar por primera vez sin parámetros en la URL, se carga por defecto una comparativa relevante (ej. `SMI` vs `IPC` vs `Alquiler`) para demostrar el funcionamiento inmediato de la herramienta.

### 4.2. Motor de Gráficos Comparativos (El Núcleo del Producto)
El componente de gráfico debe resolver matemáticamente la comparación de variables con distintas escalas y frecuencias:

1. **Alineación Temporal:**
   - Unificar el eje X (`YYYY-MM`) tomando la unión de fechas de las series activas dentro del rango seleccionado.
   - Si una serie tiene datos anuales o trimestrales puntualizados en meses (ej. el SMI que cambia en enero de cada año), debe soportar renderizado tipo escalón (`stepAfter`) o interpolación limpia sin romper la línea.
2. **Modos de Escala (Toggle Obligatorio):**
   - **Modo Índice Base 100 (Activado automáticamente cuando hay 2 o más métricas):**
     - Toma el primer punto de datos válido dentro del rango temporal visible para cada serie como valor base $V_0$, y transforma cada punto posterior $V_t$ mediante:
       $$\text{Índice}_t = \left(\frac{V_t}{V_0}\right) \times 100$$
     - Permite comparar visualmente variaciones relativas (ej. *+60,9% vs +22,6%*) sin distorsiones de escala.
     - El tooltip al pasar el cursor debe mostrar **tanto el índice Base 100 como el valor real original con su unidad** (ej. `160,9 pts (1.184 €/mes)`).
   - **Modo Valores Reales:**
     - Activado por defecto cuando solo hay 1 métrica seleccionada.
     - Si hay 2 métricas con unidades distintas (ej. `€/mes` y `%`), habilita un **Doble Eje Y** (izquierda y derecha). Si hay más de 2 unidades distintas, sugiere volver a Base 100.
3. **Controles Temporales:**
   - Botones rápidos de ventana temporal: `1A`, `3A`, `5A`, `10A`, `Todo`, además de selectores `Desde` / `Hasta` (`YYYY-MM`).
   - Al cambiar el rango temporal en **Modo Base 100**, el punto `100` se recalcula dinámicamente al inicio del nuevo rango seleccionado.
4. **Sincronización con URL (Deep Linking):**
   - El estado de la comparativa (métricas activas, rango de fechas y modo de escala) debe reflejarse en los query params de la URL (ej. `?m=smi,ipc,alquiler-m2&from=2018-01&mode=base100`) para que cualquier usuario pueda copiar la URL del navegador y compartir exactamente el mismo cruce de datos.

### 4.3. Panel de Trazabilidad y Fuentes (Debajo del Gráfico)
Por cada métrica activa en el gráfico, se renderiza una tarjeta informativa limpia con:

"""

Responsabilidad única (SRP): Gestión de persistencia local en staging y sincronización con data.

from datetime import date

def validate_and_stage(
    items: dict | list[dict],
    staging_dir: Path = Path("./staging"),
) -> bool:
    """
    Verifica que las tarjetas y sus series no estén vacías ni contengan valores negativos antes de guardarlas en ./staging.
    """
    print(f"\n[3/4] 🧪 Validando tarjetas y guardando datos en ({staging_dir}/)...")
    items_staging_dir = staging_dir / "items"
    items_staging_dir.mkdir(parents=True, exist_ok=True)

    items_list = items if isinstance(items, list) else [items]
    existing_staging_entries = {}

    staging_index_path = staging_dir / "items.json"
    if staging_index_path.exists():
        try:
            with open(staging_index_path, "r", encoding="utf-8") as f:
                for entry in json.load(f):
                    existing_staging_entries[entry["id"]] = entry
        except Exception:
            pass

    for item_payload in items_list:
        item_id = item_payload.get("id")
        if not item_id:
            print("\n      ❌ ERROR: La tarjeta no tiene 'id'")
            return False

        data_points = item_payload.get("dataPoints", [])
        if not data_points:
            print(f"\n      ❌ ERROR: dataPoints vacíos en tarjeta {item_id}")
            return False

        for pt in data_points:
            val = pt.get("value")
            if val is None:
                print(f"\n      ❌ ERROR: Valor nulo en {item_id}: {pt}")
                return False

        # Guardar archivo de la tarjeta individual
        with open(items_staging_dir / f"{item_id}.json", "w", encoding="utf-8") as f:
            json.dump(item_payload, f, ensure_ascii=False, indent=2)

        # Obtener el valor principal/total para el índice items.json
        last_dp = data_points[-1]
        latest_val = 0
        val_raw = last_dp.get("value")
        if isinstance(val_raw, (int, float)):
            latest_val = val_raw
        elif isinstance(val_raw, list):
            for entry in val_raw:
                if isinstance(entry, dict):
                    if "total" in entry:
                        latest_val = entry["total"]
                        break
                    elif latest_val == 0:
                        latest_val = list(entry.values())[0]

        sources = item_payload.get("sources")
        last_upd = None
        if isinstance(sources, list) and sources:
            last_upd = sources[0].get("lastUpdated")
        if not last_upd:
            last_upd = item_payload.get("source", {}).get("lastUpdated") or item_payload.get("last_updated") or date.today().isoformat()

        existing_staging_entries[item_id] = {
            "id": item_id,
            "category": item_payload.get("category", "Pensiones y Demografía"),
            "question": item_payload.get("question", item_id),
            "unit": item_payload.get("unit", ""),
            "latestValue": latest_val,
            "latestYear": str(last_dp.get("year", "")),
            "lastUpdated": last_upd,
        }

    with open(staging_dir / "items.json", "w", encoding="utf-8") as f:
        json.dump(list(existing_staging_entries.values()), f, ensure_ascii=False, indent=2)

    print(f"      ✓ Validación superada: {len(items_list)} tarjeta(s) guardada(s) en {staging_dir}/items/")
    return True


def promote_to_data(
    prefix_filter: str = "",
    staging_dir: Path = Path("./staging"),
    data_dir: Path = Path("./data"),
) -> None:
    """
    Sincroniza las tarjetas en staging con ./data/items/<id>.json, ./data/items.json y ./data/metadata.json.
    """
    print(f"\n[4/4] 🚀 Promocionando datos a carpeta de producción ({data_dir}/)...")
    items_staging_dir = staging_dir / "items"
    live_items_dir = data_dir / "items"
    live_items_dir.mkdir(parents=True, exist_ok=True)

    # Limpiar obsoletos en metrics/ si existían de versiones anteriores
    live_metrics_dir = data_dir / "metrics"
    if live_metrics_dir.exists():
        shutil.rmtree(live_metrics_dir)

    src_files = list(items_staging_dir.glob("*.json"))
    for src_file in tqdm(src_files, desc="      Copiando a ./data/items", ncols=80):
        shutil.copy2(src_file, live_items_dir / src_file.name)

    # Actualizar data/items.json combinando existentes con staging
    live_items_index_path = data_dir / "items.json"
    existing_items = {}
    if live_items_index_path.exists():
        try:
            with open(live_items_index_path, "r", encoding="utf-8") as f:
                content = json.load(f)
                if isinstance(content, list):
                    for item in content:
                        existing_items[item["id"]] = item
        except Exception:
            pass

    staging_items_index_path = staging_dir / "items.json"
    if staging_items_index_path.exists():
        with open(staging_items_index_path, "r", encoding="utf-8") as f:
            for item in json.load(f):
                existing_items[item["id"]] = item

    items_list = list(existing_items.values())
    with open(live_items_index_path, "w", encoding="utf-8") as f:
        json.dump(items_list, f, ensure_ascii=False, indent=2)

    # Actualizar data/metadata.json
    metadata_path = data_dir / "metadata.json"
    meta_payload = {
        "last_updated": date.today().isoformat(),
        "total_items": len(items_list),
        "categories": [
            "Vivienda",
            "Economía y Empleo",
            "Sanidad",
            "Pensiones y Demografía"
        ]
    }
    with open(metadata_path, "w", encoding="utf-8") as f:
        json.dump(meta_payload, f, ensure_ascii=False, indent=2)

    print(f"      ✓ {len(src_files)} tarjeta(s) promocionada(s) en {live_items_dir}/")
    print(f"      ✓ Índice de tarjetas actualizado en {live_items_index_path} ({len(items_list)} entradas).")
    print(f"      ✓ Metadatos globales actualizados en {metadata_path}.")
    print(f"\n🎉 ¡Proceso completado con éxito!")

def slugify(text: str) -> str:
    text = text.lower()
    text = re.sub(r'[áàäâ]', 'a', text)
    text = re.sub(r'[éèëê]', 'e', text)
    text = re.sub(r'[íìïî]', 'i', text)
    text = re.sub(r'[óòöô]', 'o', text)
    text = re.sub(r'[úùüû]', 'u', text)
    text = re.sub(r'ñ', 'n', text)
    text = re.sub(r'[^a-z0-9]+', '-', text)
    return text.strip('-')

def parse_legacy_ine(raw_data: list) -> dict:
    data = {}
    for serie in raw_data:

            parts = [p.strip() for p in nombre.split(".")]
            c = parts[-1] if parts[-1] else parts[-2]
            if c:
                if c not in data:

                for d in serie.get("Data", []):
                    if d.get("Valor") is not None:
                        y = str(d["Anyo"])
                        if int(y) <= 2020:

    return data

"""
Cliente HTTP dedicado a consultar las tablas de la API oficial del INE.
Responsabilidad única (SRP): Comunicación e integración con la API Tempus JS del INE.
"""

import json
import requests
from tqdm import tqdm

INE_API_BASE_URL = "https://servicios.ine.es/wstempus/js/ES/DATOS_TABLA"


def fetch_ine_table(table_id: str, tip: str = "AM", timeout: int = 60) -> list:
    """
    Consulta la API Tempus del INE para obtener los datos crudos de una tabla determinada,
    mostrando una barra de progreso en tiempo real con tqdm.
    """
    url = f"{INE_API_BASE_URL}/{table_id}?tip={tip}"
    print(f"\n[1/4] 🌐 Descargando datos desde la API del INE (Tabla {table_id})...")

    with requests.get(url, stream=True, timeout=timeout) as response:
        response.raise_for_status()
        total_size = int(response.headers.get("content-length", 0))
        chunk_size = 16384
        chunks = []

        with tqdm(
            total=total_size if total_size > 0 else None,
            unit="B",
            unit_scale=True,
            unit_divisor=1024,
            desc="      Descarga INE",
            ncols=80,
        ) as pbar:
            for chunk in response.iter_content(chunk_size=chunk_size):
                if chunk:
                    chunks.append(chunk)
                    pbar.update(len(chunk))

        raw_bytes = b"".join(chunks)
        print("      ⌛ Deserializando respuesta JSON...")
        try:
            data = json.loads(raw_bytes.decode("utf-8"))
        except json.JSONDecodeError as e:
            raise RuntimeError(
                f"Error deserializando JSON de la tabla INE {table_id}. "
                f"La respuesta fue truncada o es inválida ({len(raw_bytes)} bytes recibidos). "
                f"Detalle: {e}"
            ) from e
        print(f"      ✓ Respuesta recibida: {len(data)} series de datos crudas obtenidas.")
        return data

"""
Módulo especializado en la normalización y limpieza de cadenas de texto.
Responsabilidad única (SRP): Procesamiento de texto y conversión a slugs válidos.
"""

import re


def slugify(text: str) -> str:
    """
    Transforma un texto o nombre en un identificador limpio (slug) sin acentos ni caracteres especiales.
    """
    text = text.lower().strip()
    replacements = {
        "á": "a", "é": "e", "í": "i", "ó": "o", "ú": "u",
        "ñ": "n", "ü": "u", "(": "", ")": "", ",": ""
    }
    for k, v in replacements.items():
        text = text.replace(k, v)
    return re.sub(r"[^a-z0-9]+", "-", text).strip("-")

import fs from "node:fs";
import path from "node:path";

const ROOT_DIR = process.cwd();
const OUTPUT_FILE = path.join(ROOT_DIR, "repo-bundle.txt");

const IGNORE_DIRS = ["node_modules", ".next", "out", ".git", "data", "public", "staging", ".venv", ".opencode"];
const IGNORE_FILES = [
  "all-typescript-code.ts",
  "repo-bundle.txt",
  "package-lock.json",
  "uv.lock",
  "countriesGeo.json",
  "landGeo.json"
];

const ALLOWED_EXTENSIONS = [".ts", ".tsx", ".js", ".py", ".css", ".json", ".md", ".toml", ".mjs"];

function shouldIgnore(relPath, fileName) {
  const normalized = relPath.split(path.sep).join("/");
  if (normalized.startsWith("data/") || normalized.startsWith("public/data/") || normalized.startsWith("staging/")) return true;
  if (normalized.includes("countriesGeo.json") || normalized.includes("landGeo.json")) return true;
  if (IGNORE_FILES.includes(fileName)) return true;
  return false;
}

function walkDir(dir, fileList = []) {
  const entries = fs.readdirSync(dir, { withFileTypes: true });
  for (const entry of entries) {
    if (IGNORE_DIRS.includes(entry.name)) continue;
    const res = path.join(dir, entry.name);
    const relPath = path.relative(ROOT_DIR, res);
    if (shouldIgnore(relPath, entry.name)) continue;

    if (entry.isDirectory()) {
      walkDir(res, fileList);
    } else if (entry.isFile()) {
      const ext = path.extname(entry.name);
      if (ALLOWED_EXTENSIONS.includes(ext) || ["package.json", "tsconfig.json", "pyproject.toml"].includes(entry.name)) {
        fileList.push(res);
      }
    }
  }
  return fileList;
}

function bundleRepo() {
  const files = walkDir(ROOT_DIR);
  let output = `/**\n * FACTORES REPOSITORY SOURCE CODE BUNDLE\n * Generated on: ${new Date().toISOString()}\n */\n\n`;

  for (const file of files) {
    const relPath = path.relative(ROOT_DIR, file);
    const content = fs.readFileSync(file, "utf-8");
    output += `// ==========================================\n`;
    output += `// FILE: ${relPath}\n`;
    output += `// ==========================================\n\n`;
    output += content;
    output += `\n\n`;
  }

  fs.writeFileSync(OUTPUT_FILE, output, "utf-8");
  console.log(`[Bundle] Successfully bundled ${files.length} repository source files into ${OUTPUT_FILE}`);
}

bundleRepo();

function validateAndBuildIndex() {
  console.log("[Validation] Scanning ./staging/items directory...");
  ensureDirs();

  const itemsDir = path.join(STAGING_DIR, "items");
  const files = fs.existsSync(itemsDir)
    ? fs.readdirSync(itemsDir).filter((f) => f.endsWith(".json"))
    : [];

  const indexItems = [];

  for (const file of files) {
    const filePath = path.join(itemsDir, file);
    let item;
    try {
      item = JSON.parse(fs.readFileSync(filePath, "utf-8"));
    } catch (e) {
      throw new Error(`Invalid JSON syntax in ${filePath}: ${e.message}`);
    }

    if (!item.id || !item.question || !item.category) {
      throw new Error(`Item in ${file} is missing required fields (id, question, category).`);
    }

    if (!Array.isArray(item.sources) || item.sources.length === 0) {
      throw new Error(`Item ${file} must include a standardized 'sources' array with at least one source (AC 1.1).`);
    }

    for (const src of item.sources) {
      if (!src.institution || typeof src.institution !== "string") {
        throw new Error(`Source in ${file} is missing required 'institution' string (AC 1.2).`);
      }
      if (!src.title || typeof src.title !== "string") {
        throw new Error(`Source in ${file} is missing required 'title' string (AC 1.2).`);
      }
      if (!src.url || typeof src.url !== "string") {
        throw new Error(`Source in ${file} is missing required 'url' string (AC 1.2).`);
      }
    }

    const points = item.dataPoints || (item.metrics && Object.values(item.metrics)[0]?.series);
    if (!Array.isArray(points) || points.length === 0) {
      throw new Error(`Item ${file} must have a non-empty dataPoints or series array.`);
    }

    for (const p of points) {
      const val = p.value;
      if (typeof val === "number") {
        if (Number.isNaN(val) || !Number.isFinite(val)) {
          throw new Error(`Invalid or corrupted numeric value '${val}' in ${file} (NaN/null/Infinity).`);
        }
      } else if (Array.isArray(val)) {
        for (const entry of val) {
          if (!entry || typeof entry !== "object") {
            throw new Error(`Invalid point element in ${file}: expected object, got ${typeof entry}`);
          }
          for (const [k, num] of Object.entries(entry)) {
            if (typeof num !== "number" || Number.isNaN(num) || !Number.isFinite(num)) {
              throw new Error(`Invalid numeric value '${num}' for key '${k}' in ${file}.`);
            }
          }
        }
      } else {
        throw new Error(`Invalid value type '${typeof val}' in ${file}. Expected number or array of objects.`);
      }

      const dateVal = p.year || p.date;
      if (!dateVal) {
        throw new Error(`Data point in ${file} missing year/date field.`);
      }
    }

    const lastPoint = points[points.length - 1];
    let latestVal = 0;
    if (typeof lastPoint.value === "number") {
      latestVal = lastPoint.value;
    } else if (Array.isArray(lastPoint.value)) {
      const totalObj = lastPoint.value.find((v) => v && typeof v === "object" && "total" in v) || lastPoint.value[0];
      latestVal = totalObj ? Object.values(totalObj)[0] : 0;
    }

    const firstSource = item.sources?.[0] || item.source;
    indexItems.push({
      id: item.id,
      category: item.category,
      question: item.question,
      unit: item.unit || "",
      latestValue: latestVal,
      latestYear: lastPoint.year || lastPoint.date,
      lastUpdated: firstSource?.lastUpdated || item.last_updated || new Date().toISOString().split("T")[0]
    });
  }

  // Write items index and metadata
  const metadata = {
    last_updated: new Date().toISOString().split("T")[0],
    total_items: indexItems.length,
    categories: ["Vivienda", "Economía y Empleo", "Sanidad", "Pensiones y Demografía"]
  };

  fs.writeFileSync(path.join(STAGING_DIR, "items.json"), JSON.stringify(indexItems, null, 2));
  fs.writeFileSync(path.join(STAGING_DIR, "metadata.json"), JSON.stringify(metadata, null, 2));

  console.log(`[Validation] Validated ${indexItems.length} items successfully.`);
}

function copyRecursive(src, dest) {
  if (fs.existsSync(dest)) {
    fs.rmSync(dest, { recursive: true, force: true });
  }
  fs.mkdirSync(dest, { recursive: true });

  const entries = fs.readdirSync(src, { withFileTypes: true });
  for (const entry of entries) {
    const srcPath = path.join(src, entry.name);
    const destPath = path.join(dest, entry.name);
    if (entry.isDirectory()) {
      copyRecursive(srcPath, destPath);
    } else {
      fs.copyFileSync(srcPath, destPath);
    }
  }
}

function sync() {
  console.log("[Sync] Syncing ./staging to ./data...");
  fs.mkdirSync(path.join(DATA_DIR, "items"), { recursive: true });
  fs.mkdirSync(path.join(DATA_DIR, "es", "items"), { recursive: true });

  copyRecursive(path.join(STAGING_DIR, "items"), path.join(DATA_DIR, "items"));
  copyRecursive(path.join(STAGING_DIR, "items"), path.join(DATA_DIR, "es", "items"));

  if (fs.existsSync(path.join(STAGING_DIR, "metadata.json"))) {
    fs.copyFileSync(path.join(STAGING_DIR, "metadata.json"), path.join(DATA_DIR, "metadata.json"));
    fs.copyFileSync(path.join(STAGING_DIR, "metadata.json"), path.join(DATA_DIR, "es", "metadata.json"));
  }
  if (fs.existsSync(path.join(STAGING_DIR, "items.json"))) {
    fs.copyFileSync(path.join(STAGING_DIR, "items.json"), path.join(DATA_DIR, "items.json"));
    fs.copyFileSync(path.join(STAGING_DIR, "items.json"), path.join(DATA_DIR, "es", "items.json"));
  }

  console.log("[Sync] Syncing ./data to ./public/data...");
  fs.mkdirSync(PUBLIC_DATA_DIR, { recursive: true });
  copyRecursive(DATA_DIR, PUBLIC_DATA_DIR);

  const publicEnDir = path.join(PUBLIC_DATA_DIR, "en");
  const dataEnDir = path.join(DATA_DIR, "en");
  if (fs.existsSync(dataEnDir)) {
    copyRecursive(dataEnDir, publicEnDir);
  }

  console.log("[Sync] Data sync complete!");
}

try {
  validateAndBuildIndex();
  sync();
} catch (err) {
  console.error("[Pipeline Error]", err.message);
  process.exit(1);
}
