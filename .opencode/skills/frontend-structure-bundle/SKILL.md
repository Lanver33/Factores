# Frontend Structure Bundle

Skill para empaquetar la estructura de directorios y archivos de frontend omitiendo los archivos `.json` en `frontend-structure-bundle.txt`.

## Instrucciones

Para ejecutar esta skill y generar `frontend-structure-bundle.txt`:

```sh
npm --prefix .opencode/skills/frontend-structure-bundle run bundle
```
