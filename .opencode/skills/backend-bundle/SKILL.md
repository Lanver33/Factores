# Backend Bundle

Skill para empaquetar y consolidar el código fuente del backend y la estructura de directorios en `backend-bundle.txt`.

## Instrucciones

Para ejecutar esta skill y generar `backend-bundle.txt`:

```sh
npm --prefix .opencode/skills/backend-bundle run bundle
```
